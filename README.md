#  Job Portal

A Full Stack Job Portal built using React, Supabase, PostgreSQL, and n8n.

## Features

- 🔐 User Authentication
- 🏢 Add Companies
- 📋 View Companies
- 💼 Browse Jobs
- 🌐 External Jobs API
- ⚡ n8n Workflow Automation
- 🗄️ Supabase PostgreSQL Database

---

## Tech Stack

- React
- Vite
- JavaScript
- Supabase
- PostgreSQL
- n8n
- CSS
